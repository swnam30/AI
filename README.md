# PortScanner — nmap 유사 포트 스캐너

FortiGate 점검 단일 HTML 도구의 **⑦ 포트/서비스 위험도 분석** 탭과 연동하기 위한
독립 실행형(EXE) 포트 스캐너입니다. 단일 HTML(브라우저)에서는 보안 정책상 원격
포트 스캔이 불가능하므로, 실제 스캔은 이 EXE 가 수행하고 **결과(nmap 형식)를
HTML 도구에 붙여넣어** 위험도를 분석하는 워크플로우입니다.

```
방식 A (실시간 연동, 권장):
  [HTML ⑦탭 클릭] --fetch--> [PortScanner.exe --serve] --스캔--> 결과 JSON --> [HTML 자동 표시]

방식 B (붙여넣기):
  [PortScanner.exe] --스캔--> nmap 형식 결과 --복사/붙여넣기--> [HTML ⑦ 포트 분석 탭] --> 위험도 분류
```

## 주요 기능

- **포트 개폐 확인** — TCP connect 스캔 (멀티스레드, 관리자 권한 불필요)
- **서비스 식별** — 배너 그래빙 + 포트 매핑 (`ssh`, `http`, `mysql` 등)
- **버전/제품 탐지** — 배너에서 OpenSSH, nginx, IIS, FortiOS 등 추출
- **호스트 식별 (TTL 이외 다중 신호)** — 아래 여러 방법을 조합해 "무슨 호스트/OS"인지 판별
  - **TTL 분석** — ping 의 TTL(64=Linux / 128=Windows / 255=네트워크 장비)
  - **NetBIOS 조회(UDP 137)** — 실제 **컴퓨터 이름 + 워크그룹/도메인 + MAC 주소** (Windows·SMB 장비)
  - **SNMP sysDescr(UDP 161, community `public`)** — 장비 **모델·OS 전체 설명** (FortiGate·Cisco·프린터 등)
  - **배너 근거** — Server 헤더, OpenSSH/IIS 등 제품 문자열
- **호스트 정보** — 정방향/역방향 DNS, 도달 여부, 응답시간(RTT)
- **포트 위험도 DB 213개** — IANA well-known(0–1023) 전반 + 주요 registered 포트
  (DB·원격접속·OT/ICS(Modbus/S7/BACnet)·백도어 포트까지 위험도·권고 포함)
- **네트워크 대역 스윕 (IP 충돌 예방)** — 대역 내 **사용 중 / 비어있는 IP** 판별
  - TCP 프로브 + **ARP 테이블** + ICMP 를 조합해 방화벽 뒤 호스트까지 탐지
  - 점유 IP 의 **MAC·호스트명**까지 표시 → 고정 IP 배정 전 충돌 사전 확인
- **nmap 형식 출력** — HTML 도구 ⑦ 탭에 그대로 붙여넣기 가능
- **결과 저장** — 리포트 + nmap 블록을 `.txt` 로 저장

> NetBIOS/SNMP 는 대상이 해당 서비스를 열어둔 경우에만 응답합니다(주로 사내망 LAN).
> 인터넷 너머의 호스트나 UDP 137/161 이 차단된 경우에는 표시되지 않을 수 있습니다.

## 사용법

### 더블클릭 실행 (모드 선택)
`PortScanner.exe` 를 더블클릭하면 실행 모드를 먼저 선택하는 화면이 뜹니다.

```
  실행 모드를 선택하세요:
    1) 단일 스캔 모드   - IP 를 직접 입력해 콘솔에서 스캔
    2) 서버 모드        - HTML ⑦ 탭의 '실시간 스캔' 과 연동
    q) 종료
```

- **1) 단일 스캔 모드** — 대상 IP·포트 범위를 물어보고 콘솔에서 바로 스캔합니다.
- **2) 서버 모드** — 브리지 서버를 켭니다. HTML ⑦ 탭에서 실시간 스캔을 사용할 수 있습니다.
  포트를 물어보며(기본 8765) 그대로 두려면 Enter.

> 서버는 exe 와 **같은 프로세스**에서 실행됩니다. 따라서 **콘솔 창을 닫거나
> `Ctrl+C` 를 누르면 서버도 함께 종료**됩니다.

### 명령행
```bat
PortScanner.exe 192.168.1.1                 :: 주요 공통 포트 스캔
PortScanner.exe 192.168.1.1 -p 1-1024       :: well-known 포트
PortScanner.exe 192.168.1.1 -p all          :: 전체 65535 포트 (느림)
PortScanner.exe 10.0.0.5 -p 22,80,443,3389  :: 특정 포트만
PortScanner.exe 10.0.0.5 -o result.txt      :: 결과 파일 저장
PortScanner.exe host.example.com -q          :: 진행표시 없이 결과만
```

### 대역 스윕 (IP 충돌 예방)
사내 여러 대역에서 고정 IP 를 배정하기 전, 대역 내 이미 사용 중인 IP 를
미리 확인해 **IP 충돌을 예방**합니다. TCP 프로브 + ARP 테이블 + ICMP 를
조합하므로 ICMP 를 막아둔 호스트도 탐지합니다.

```bat
PortScanner.exe --sweep 192.168.10.0/24        :: 대역 전체 스윕
PortScanner.exe --sweep 10.0.0.1-100           :: 범위 지정
PortScanner.exe --sweep 172.16.5.0/24 --no-ping :: ICMP 생략(빠름)
PortScanner.exe --sweep 192.168.10.0/24 -o free.txt
```

- 결과는 **점유 IP(MAC·호스트명 포함)** 와 **미사용 IP 요약**으로 나옵니다.
- HTML ⑦ 탭의 **🌐 대역 스캔** 버튼으로도 같은 기능을 쓸 수 있습니다(서버 모드 필요).
  버튼을 누르면 대역의 **모든 IP 가 격자로 즉시 표시**되고, 스캔이 끝난 IP 부터
  실시간으로 색이 바뀝니다(회색=확인 중, 빨강=점유, 초록=미사용) — 진행바와
  단계 표시로 멈춘 것이 아니라 진행 중임을 바로 알 수 있습니다.
- ⚠️ **ARP 는 같은 L2 세그먼트에서 가장 정확**합니다. 정확도를 높이려면 확인하려는
  대역에 스캔 PC 를 두고 실행하세요. (라우터 너머 대역은 ARP 정보가 없어
  ICMP/TCP 응답에만 의존 → 정확도가 낮아질 수 있음)
- 존재 여부 판별은 **30개 프로브 포트를 동시(논블로킹)로 검사**합니다. 여기에는
  SIP(5060/5061)·RTSP(554)·프린터(9100)·H.323(1720) 등 IP 전화·CCTV·프린터 등
  **실제 장비 포트**가 포함되어, 특정 서비스 포트만 여는 장비도 놓치지 않습니다.
- **정밀 모드**(`--deep`, HTML `정밀` 체크): 전체 주요 포트(약 80개)로 존재 여부를
  판별해 방화벽 뒤 장비 탐지율을 더 높입니다(느려짐). 라우터 너머 대역이거나
  ICMP·ARP 가 안 통하는 환경에서 유용합니다.

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| `-p, --ports` | `top` \| `all` \| `1-1024` \| `22,80,443` | `top` |
| `-t, --timeout` | 포트당 연결 타임아웃(초) | `1.0` |
| `-w, --workers` | 동시 스캔 스레드 수 | `200` |
| `-o, --output` | 결과 저장 파일 경로 | 없음 |
| `--serve` | HTML 연동 브리지 서버 모드로 실행 | - |
| `--serve-host` | 브리지 바인드 호스트 | `127.0.0.1` |
| `--serve-port` | 브리지 포트 | `8765` |
| `--no-color` | 컬러 출력 끄기 | - |
| `-q, --quiet` | 진행 표시 없이 결과만 | - |

브리지 서버 실행 예:
```bat
PortScanner.exe --serve                    :: 127.0.0.1:8765 에서 대기
PortScanner.exe --serve --serve-port 8766  :: 포트 변경
```

## HTML 도구와 연동하는 방법

두 가지 방식이 있습니다. **방식 A(브리지 연동)** 는 HTML에서 클릭만으로 실제
스캔이 실행되어 가장 편리하고, **방식 B(붙여넣기)** 는 exe 를 서버로 띄우지
않고 결과만 수동으로 옮기는 방법입니다.

### 방식 A. 실시간 스캔 — HTML 클릭 → exe 실행 (권장)

> 브라우저 보안 정책상 HTML 은 로컬 프로그램을 직접 실행할 수 없으므로,
> exe 를 **로컬 브리지 서버**로 띄우고 HTML 이 `127.0.0.1` 로 요청을 보내는
> 구조로 연결합니다.

```
[HTML ⑦탭에서 IP 입력 후 "실시간 스캔" 클릭]
      │ fetch(http://127.0.0.1:8765/scan?target=IP)
      ▼
[PortScanner.exe --serve]  ← 백그라운드 로컬 서버
      │ 실제 포트 스캔 수행
      ▼
[결과 JSON → HTML이 호스트 정보 표시 + 위험도 자동 분석]
```

1. **브리지 서버 실행** — 아래 중 하나:
   - `start-bridge.bat` 더블클릭, 또는
   - 명령창에서 `PortScanner.exe --serve`
   (기본 주소 `http://127.0.0.1:8765`, 다른 포트는 `--serve-port 8766`)
2. `FortiGate_점검도구.html` 을 브라우저로 엽니다.
3. **⑦ 포트/서비스 위험도 분석** 탭으로 이동하면 우측 상단 상태칩이
   **● 연결됨** 으로 바뀝니다. (안 바뀌면 **🔌 브리지 확인** 클릭)
4. **대상 IP** 입력 → **포트 범위** 선택 → **🔍 실시간 스캔** 클릭.
5. exe 가 스캔을 수행하고, HTML 에 **호스트 정보(DNS/TTL/추정 OS 등)** 와
   **포트별 위험도(High/Medium/Low/Safe)** 가 자동으로 표시됩니다.

> 브리지 서버 창은 스캔하는 동안 켜 두어야 합니다. 종료는 그 창에서 `Ctrl+C`.

### 방식 B. 결과 붙여넣기 (서버 없이)

1. `PortScanner.exe` 로 대상 IP 를 스캔합니다.
2. 출력 하단의 **`[ HTML 도구 ⑦ 포트 분석 탭에 붙여넣기용 (nmap 형식) ]`** 블록을 복사합니다.
   ```
   22/tcp   open  ssh
   80/tcp   open  http
   3389/tcp open  ms-wbt-server
   ```
3. HTML 점검 도구 → **⑦ 포트/서비스 위험도 분석** 탭 → 입력창에 붙여넣고 **🔍 분석** 클릭.
4. 포트별 위험도(High/Medium/Low/Safe)와 권고사항이 자동 분류됩니다.

## EXE 빌드 방법

### 방법 A. GitHub Actions (권장, 자동)
이 브랜치에 push 하면 `.github/workflows/build-exe.yml` 가 **Windows 러너에서
자동으로 EXE 를 빌드**합니다. 완료 후 GitHub → **Actions** 탭 → 해당 실행 →
**Artifacts** 에서 `PortScanner-windows-exe` 를 다운로드하세요.
수동 실행은 Actions 탭에서 **Run workflow** (`workflow_dispatch`) 로도 가능합니다.

### 방법 B. 로컬 Windows PC 에서 빌드
Python 3.8+ 가 설치된 Windows 에서:
```bat
build.bat
```
빌드가 끝나면 `dist\PortScanner.exe` 가 생성됩니다.

수동으로 하려면:
```bat
pip install pyinstaller
pyinstaller --onefile --console --name PortScanner port_scanner.py
```

### 소스로 바로 실행 (빌드 없이)
Python 이 설치되어 있다면 EXE 없이도 실행 가능합니다:
```bat
python port_scanner.py 192.168.1.1
```
> 표준 라이브러리만 사용하므로 추가 패키지 설치가 필요 없습니다.

## ⚠️ 사용 시 주의

포트 스캔은 **본인이 소유하거나 명시적으로 스캔 허가를 받은 시스템**에만
사용해야 합니다. 허가 없이 타인의 네트워크/호스트를 스캔하는 행위는 관련 법률
(정보통신망법 등) 위반이 될 수 있습니다. 이 도구는 사내 자산 점검·감사 등
**정당한 권한이 있는 환경**에서의 사용을 전제로 합니다.
